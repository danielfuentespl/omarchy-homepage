# Changelog

## 0.1.0

- Initial native Omarchy/Quickshell Homepage client and bar widget.
- Poll, search and open Homepage services with bounded display data and per-service `UNKNOWN` status.
- Optional MCP integration with Secret Service token storage, read-only `services.yaml` viewing, and a guarded Add service flow with explicit confirmation and read-back verification. There is no general YAML editor.
